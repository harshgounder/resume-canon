# Pre-submit checklist

Print this or keep it open. Ten minutes.

## Machine

- [ ] `python3 tools/parse_check.py resume.pdf` reports a text layer
- [ ] Email, phone, links and years all found in the extracted text
- [ ] Section headings detected
- [ ] No column scramble warning
- [ ] `python3 tools/resume_lint.py resume.pdf` has zero errors
- [ ] File under 1MB

## Document

- [ ] One page (student) or justified length
- [ ] A4 or Letter, matching the market
- [ ] One column, no tables, no text boxes
- [ ] Contact in the body, not in a header or footer
- [ ] Dates in one format, "Present" spelled out
- [ ] Titles spelled out, posted title in parentheses
- [ ] Degree written as local name plus international equivalent
- [ ] Every bullet is one claim, one or two lines
- [ ] Every bullet starts with a verb (except awards and publications)
- [ ] Every number is one you can defend for two minutes

## Content

- [ ] No objective statement
- [ ] No "references available on request"
- [ ] No soft skills list
- [ ] No skill bars, icons, or rating dots
- [ ] No photo unless the channel requires it
- [ ] No technologies you cannot defend
- [ ] Contest ranks have a denominator
- [ ] Links resolve, checked in the PDF not the source

## Application

- [ ] Top third rewritten for this role
- [ ] Job description terms appear once, exactly
- [ ] Title in the document matches the posting
- [ ] Education fields filled by hand in the portal
- [ ] Knockout answers deliberate
- [ ] File named Firstname_Lastname_Role.pdf
- [ ] Sent to yourself and opened on a phone
