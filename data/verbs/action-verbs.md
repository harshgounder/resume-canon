# Action verbs

A working bank for `docs/` and for anyone rewriting a resume. Organised by what the verb claims, not alphabetically, because the first decision is what kind of act you performed and the second is which word fits it.

Companion file: `research/wave-03/linguistics.md` explains why these choices matter and grades the sources.

## How to use this

1. Pick the category that matches the act. If a bullet fits two categories, it probably contains two claims and should be split.
2. Read the example. If your bullet would not survive the same shape (verb, object, size, outcome), the verb is not your problem, the missing detail is.
3. Do not use the same verb twice in one role. Repetition of "built" four times reads as one skill used four times.
4. Past tense for roles you have left, present for the role you hold. Every example below is past tense unless marked.
5. Spelling: this file uses US forms (analyzed, prioritized). UK and Indian applications should use analysed, prioritised, organised. Pick one set and keep it for the whole document. Mixing is the most common proofreading miss I see in student CVs.

The verbs are ordinary on purpose. A resume does not need rare words, it needs accurate ones.

## Building

For making something that did not exist. The strongest category for students and early-career engineers, because the artifact is the evidence.

| Verb | What it claims | Example bullet |
|---|---|---|
| Built | You constructed the thing end to end | Built a document intake service that processed 4,000 files a day at 99.5% parse success |
| Designed | You made the structural decisions, not just the code | Designed the schema for a 60-table warehouse serving 12 analysts |
| Wrote | You authored the text or the code, plainly | Wrote the API reference for 38 endpoints, now the team's onboarding document |
| Developed | Broader than built, often a feature or module | Developed the refund workflow used by 3 support teams |
| Implemented | You turned a spec into working code | Implemented retry and idempotency for a payments endpoint handling 20K calls a day |
| Shipped | It reached users | Shipped the checkout redesign to 8,000 weekly customers |
| Launched | It went public, with a date | Launched the partner portal in March, onboarding 14 partners in the first quarter |
| Prototyped | You built a throwaway to test an idea | Prototyped three ranking approaches in two weeks; the third became the production model |
| Assembled | You gathered parts into a working whole, often hardware or a team | Assembled a 12-node test cluster from retired hardware, saving $9K in cloud spend |
| Drafted | You produced a first version of a document or plan | Drafted the incident response runbook adopted by 4 on-call teams |
| Configured | You set up an existing system | Configured alerting for 30 services, cutting mean time to detect from 25 to 4 minutes |
| Deployed | You moved code into an environment | Deployed 40 releases over 6 months with no rollback |
| Established | You created something that persists, often a process | Established a weekly triage meeting that cut the open bug count from 210 to 60 |

Note on "built": it is the most overused verb in engineering resumes, and it is still usually the right one. Do not replace it with "architected" to sound senior unless you actually made the architecture decisions.

## Improving

For changing something that already existed. This is where numbers do the most work, because the baseline exists whether or not anyone recorded it.

| Verb | What it claims | Example bullet |
|---|---|---|
| Cut | You reduced a quantity, usually cost or time | Cut build time from 14 to 4 minutes by caching dependencies |
| Reduced | Same as cut, safer with percentages | Reduced duplicate refund tickets from 900 to 120 a month |
| Eliminated | You removed the problem, not just its symptom | Eliminated the nightly manual reconciliation by fixing the upstream export |
| Fixed | You repaired a specific defect | Fixed a race condition that corrupted 1 in 5,000 orders |
| Resolved | You closed an issue, often a ticket or incident | Resolved 340 support tickets in one quarter, 92% within SLA |
| Debugged | You found the cause, not just the symptom | Debugged a 3-second checkout stall caused by a missing composite index |
| Diagnosed | You named the root cause with evidence | Diagnosed a memory leak in the image worker that had been misattributed to the database |
| Refactored | You restructured code without changing behaviour | Refactored the auth module from 4,200 to 1,100 lines with no behaviour change |
| Migrated | You moved something from A to B | Migrated 240 services off a deprecated logging library in one quarter |
| Ported | You moved code to another platform or language | Ported the reporting job from Perl to Python, cutting runtime 70% |
| Rewrote | You replaced the implementation | Rewrote address validation in Python; checkout errors fell from 4.1% to 3.4% |
| Automated | You removed a human step | Automated weekly reporting, removing 6 hours of manual work per week |
| Optimized | You made a measured improvement, so it needs a measure | Optimized the search query path, cutting p95 latency from 800 to 210ms |
| Simplified | You removed complexity, measurable in steps or lines | Simplified onboarding from 11 steps to 4, cutting drop-off by half |
| Consolidated | You merged duplicates | Consolidated three vendor contracts into one, saving 15% a year |
| Recovered | You restored something lost | Recovered 2.1TB of deleted customer uploads from snapshots within 4 hours |
| Sped up | Plain language version of optimized | Sped up the nightly ETL from 5 hours to 50 minutes |

"Optimized" without a number is a claim with no content. If you cannot measure the improvement, use "simplified" or "rewrote" and describe the change instead.

## Leading

For directing people, work or decisions. These verbs are only credible with a size attached: how many people, how much money, how long.

| Verb | What it claims | Example bullet |
|---|---|---|
| Led | You directed a group toward an outcome | Led four engineers through a six-week migration with no customer downtime |
| Owned | You were accountable for the whole thing | Owned the billing service through two quarters, including on-call and roadmap |
| Ran | You operated something ongoing | Ran the weekly release process for 12 services across 3 teams |
| Managed | You had responsibility for people or a budget, with a size | Managed a $2M vendor budget and 3 direct reports |
| Coordinated | You aligned parties who did not report to you | Coordinated a launch across engineering, legal and support, hitting the announced date |
| Mentored | You developed a specific person | Mentored two juniors through their first on-call rotation |
| Coached | You improved someone's performance in a defined area | Coached a teammate from two failed interviews to an offer in three months |
| Trained | You taught a skill, usually with a group size | Trained 30 staff on the new ticketing system in four sessions |
| Onboarded | You brought someone into a system or team | Onboarded 6 new hires, cutting their time to first commit from 9 days to 3 |
| Hired | You ran or sat in hiring loops | Hired 3 engineers and rewrote the take-home that screened 80 candidates |
| Chaired | You ran a formal meeting or committee | Chaired the security review board for 22 change requests |
| Delegated | You assigned work and kept accountability | Delegated incident comms to two teammates while owning the technical fix |
| Negotiated | You reached an agreement with an outside party | Negotiated a vendor renewal 18% below the prior year's rate |
| Secured | You obtained something that was not guaranteed | Secured $40K in departmental funding for the lab's GPU cluster |
| Represented | You spoke for a group to an outside audience | Represented the team in the quarterly business review with 40 stakeholders |
| Sponsored | You used your position to back someone else's work | Sponsored a junior engineer's accessibility project through to production |

"Led" is the most inflated verb on the market. If you were one of five equals, you did not lead, you contributed. "Coordinated" or "drove the X workstream" is honest and still strong.

## Analysing

For producing a finding. The verb has to say what kind of finding, because "analyzed" alone tells a reader nothing about the output.

| Verb | What it claims | Example bullet |
|---|---|---|
| Analyzed | You examined data and produced a conclusion | Analyzed 18 months of churn data, identifying a pricing cliff at month 4 |
| Measured | You quantified something not previously quantified | Measured support handle time across 6 queues, finding a 40% gap between them |
| Modeled | You built a representation, statistical or structural | Modeled demand for 12 SKUs, cutting stockouts 25% |
| Forecast | You predicted a future quantity | Forecast quarterly volume within 6% across 8 quarters |
| Benchmarked | You compared against a reference | Benchmarked 5 vendors on latency and cost; the cheapest was also the fastest |
| Audited | You checked compliance or accuracy against a standard | Audited 1,200 records for GDPR compliance and closed 34 gaps |
| Tested | You ran a defined check | Tested 60 payment scenarios before launch, catching 9 failures |
| Validated | You confirmed a result holds | Validated the migration by reconciling 1.4M rows against the legacy system |
| Investigated | You looked into an unexplained thing | Investigated a 12% drop in signups and traced it to a broken analytics tag |
| Traced | You followed a cause through a system | Traced a data corruption bug through 4 services to a timezone assumption |
| Mapped | You documented a structure or process | Mapped the order lifecycle across 7 systems for the platform rewrite |
| Surveyed | You collected structured input from people | Surveyed 180 students on timetable clashes; 62% reported at least one |
| Reviewed | You assessed work against criteria | Reviewed 120 pull requests and wrote the team's review checklist |
| Quantified | You put a number on something previously qualitative | Quantified the cost of manual QA at 22 hours a week |
| Identified | You named the thing that mattered | Identified 3 accounts representing 45% of support volume |

"Analyzed" plus a dataset plus a finding is strong. "Analyzed data to generate insights" is a sentence with no content in any of its four nouns.

## Communicating

For moving information to people. Underused by technical candidates and overused by everyone else, usually in the form "communicated effectively".

| Verb | What it claims | Example bullet |
|---|---|---|
| Presented | You spoke to an audience, with a size | Presented the migration plan to 40 stakeholders and got sign-off in one meeting |
| Wrote | You authored the artifact | Wrote the runbook that cut incident recovery from 90 to 25 minutes |
| Documented | You recorded a system or process for others | Documented 14 undocumented endpoints, now the team's reference |
| Explained | You made something understandable to a non-expert audience | Explained model limitations to the sales team in a 30-minute session |
| Briefed | You gave someone the facts they needed to act | Briefed the exec team weekly during the outage, with one page and no jargon |
| Trained | You taught a skill (see Leading) | Trained 30 staff on the new ticketing system |
| Taught | You ran a course or a module | Taught a 10-week intro programming section to 24 students |
| Persuaded | You changed a decision | Persuaded the team to drop a feature that would have added 3 weeks for 2% of users |
| Translated | You converted between audiences or formats | Translated the security audit into a 2-page board summary |
| Published | You put work into public circulation | Published 3 papers on the scheduling algorithm, cited 40 times |
| Edited | You improved someone else's text | Edited 20 client reports for clarity before release |
| Interviewed | You collected information from people directly | Interviewed 25 users and turned the notes into the v2 requirements |

"Communicated" alone should be deleted. It is a category, not an act. The act is always presented, wrote, explained, briefed or taught.

## Operating

For keeping something running. This is the category that gets compressed unfairly, because "kept the system alive for a year" is a real achievement with no natural percentage.

| Verb | What it claims | Example bullet |
|---|---|---|
| Ran | You operated a recurring process (see Leading) | Ran nightly batch settlement for 40K transactions with zero missed windows |
| Maintained | You kept something working over time | Maintained 12 production services at 99.9% uptime for 14 months |
| Monitored | You watched a system and responded | Monitored 30 dashboards on a 24/5 rotation, catching 6 incidents before customers did |
| Operated | You used or drove equipment or a system | Operated a 5-axis CNC mill for 200 production parts at 0.02mm tolerance |
| Scheduled | You planned time or resources | Scheduled 40 shifts a week for a 12-person team across 2 sites |
| Processed | You handled volume | Processed 1,800 invoices a month with a 0.4% error rate |
| Handled | You dealt with volume, usually inbound (weak without a number) | Handled 60 to 80 tickets a week across email and chat |
| Administered | You managed a system's configuration and access | Administered the Jira instance for 90 users and 14 workflows |
| Triaged | You sorted incoming work by severity | Triaged 300 incoming bugs a quarter and set the fix order for 3 teams |
| Reconciled | You made two records agree | Reconciled 1.4M ledger rows against the payment provider, closing 200 discrepancies |
| Budgeted | You planned and tracked money | Budgeted $120K across 4 projects and closed the year 3% under |
| Procured | You bought or acquired equipment or services | Procured 20 laptops and 3 servers, negotiating 12% off list |
| Supported | You helped users or systems (weak without a number) | Supported 400 internal users across 3 time zones |
| Dispatched | You sent resources to where they were needed | Dispatched 30 field engineers a day across a 200km service area |

"Maintained" is honest and boring, which is fine. A year of uptime is a real result, and a resume that only lists builds makes the person look like they have never been on call.

## Never use

| Phrase | Why it fails | Use instead |
|---|---|---|
| Responsible for | Names a duty, not an act. Hides whether you did it or watched it. Banned by Purdue, UC Davis and UCSD. | The verb for what you actually did |
| Worked on | Hides ownership, scale and outcome. The signature of an unedited first draft. | Built, wrote, shipped, fixed, with an object |
| Assisted with | Hides your share. The reader assumes the smallest possible share. | Say what you did: wrote, ran, tested, drafted |
| Helped with | Same as assisted, with less precision | The specific act |
| Involved in | Attendance, not contribution | Your part, named |
| Participated in | Same as involved, and longer | Your part, named |
| Tasked with | Passive assignment. Says nothing about execution. | The act and the result |
| Duties included | Describes the job description, not you | The act inside the duty |
| In charge of | Ownership with no act and no size | Ran, owned, led, managed (with a number) |
| Utilized | Longer synonym of used, and it sounds like a thesaurus | Used, or a concrete verb |
| Leveraged | Corporate filler. Also the most common AI tell in 2025-2026 text. | Used, applied, built on |
| Spearheaded | Overused to the point of comedy, and it hides the team | Led, started, proposed |
| Facilitated | Vague. Can mean organised, taught, or sat in the room | Ran, taught, organised, chaired |
| Coordinated (alone) | Vague without the parties named | Coordinated X across Y and Z |
| Managed (alone) | Vague without a size | Managed 4 engineers, or managed a $2M budget |
| Handled (alone) | Vague without a volume | Handled 60 tickets a week |
| Supported (alone) | Vague without a volume or a system | Supported 400 users, or maintained the X service |
| Various / multiple / several | A number you did not count | The count, or a range |
| Successfully | Assumed. Nobody writes the failure version. | The result |
| Passionate about | A claim about feeling, not work. Common in summaries, rare in good ones. | The project that shows it |
| Hard-working / dedicated | Unfalsifiable, and it is what every template opens with | Evidence of the work |
| Team player | Jobscan lists it as a negative keyword: not quantifiable, overused | A team outcome you caused |
| Detail-oriented | The claim is contradicted by the first typo | Nothing. Delete the line |
| Results-driven | Says the person has results, without any | A result |
| Dynamic / go-getter / self-starter | Personality adjectives with no informational content | Nothing |
| Think outside the box | Idiom, no content, and it signals the opposite | The unconventional thing you did |
| Synergy / synergy-driven | Jargon from a different decade | The actual collaboration |

Two rules behind the list. First, a verb that needs an object to mean anything ("managed", "handled", "supported") is fine with the object and empty without it. Second, any word that describes your personality rather than your work can be deleted without loss, because the reader was never going to believe it anyway.

## Quick substitutions

| If you wrote | Write |
|---|---|
| Responsible for the dashboard | Built the dashboard used by 40 account managers |
| Worked on the API | Wrote 12 endpoints for the partner API |
| Helped reduce costs | Cut cloud spend 22% by moving batch jobs to spot instances |
| Assisted the senior engineer | Implemented the retry logic the senior engineer designed |
| Participated in testing | Tested 60 payment scenarios and caught 9 failures before launch |
| Involved in the migration | Migrated 30 services to the new cluster over two quarters |
| Tasked with reporting | Automated the weekly report, removing 6 hours of manual work |
| Utilized SQL to query data | Wrote SQL to reconcile 1.4M ledger rows |
| Successfully launched the feature | Launched the feature to 8,000 weekly users in March |
| Managed social media | Grew the account from 400 to 2,100 followers in five months |
