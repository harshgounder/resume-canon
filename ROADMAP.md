# Roadmap

## v1.0: the canon

- [x] 26-phase research architecture
- [x] 15 chapters in `docs/`
- [x] Wave 01 to 06 research, graded
- [x] Resume linter, parser checker, doc style linter
- [x] LaTeX, HTML, Markdown, JSON Resume, Typst templates
- [x] Worked example, compiled and tested
- [x] CI that runs the linters and builds the template

## v1.1: finish the waves

- [ ] Integrate wave 07 (economics, agentic) into chapters
- [ ] Integrate wave 08 (law, narrative, accessibility) into chapters
- [ ] Add the founders lane to the corpus chapter
- [ ] Add a `phases/` directory mirroring the 26 phases with the full evidence
- [ ] Second worked example: senior engineer, two pages

## v1.2: adversarial

- [ ] Contrarian pass: find three rules the canon gets wrong and correct them
- [ ] Uniqueness loop: find what no existing guide covers
- [ ] Self-audit: run the canon's own tools against the canon's own example
- [ ] Publish a changelog with every rule that changed and why

## v2.0: reach

- [ ] Non-English markets (German, French, Japanese, Chinese, Arabic)
- [ ] A machine-readable rules file so tools can consume the canon
- [ ] An ATS simulator that models the documented vendor behaviour
- [ ] Field-specific template variants (quant, consulting, academic)

## Not planned

- A resume builder. The ecosystem has enough, and the census shows most are
  subscription traps.
- A score. Third party scores are the thing this repo argues against.
- Scraping private documents. Public only, quoted sparingly, linked always.
