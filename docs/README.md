## Conventions

- Rules are stated as imperatives. "Do X", not "consider X".
- Where evidence is thin, the chapter says so in a box at the top.
- Numbers are sourced. Unsourced numbers are marked as folklore.
- Examples are fictional unless a real person is named and linked.
